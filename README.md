**S.E.A. D(R)IVE** is an intuitive cloud storage and file management system designed for seamless data organization.
The name S.E.A. represents the project's creators: Shahar, Eliran, and Adi.

<p align="center"> <img src="WhatsApp Image 2026-01-07 at 15.46.12 (1).jpeg" width="85%" alt="S.E.A. D(R)IVE Profile View" /> </p>

Getting Started:
To run the project, open two separate terminals and execute the following commands:
1. Backend Server: npm run start:backend
2. Frontend Client: npm run start:client

Key Features:

Smart File Management
Create folders, text files, and upload images or documents directly from your computer.

<p align="center"> <img src="WhatsApp Image 2026-01-07 at 15.46.13.jpeg" width="30%" alt="New Dive Menu" /> </p>

Search & Editor
A fast search engine to find files by name or content, with a built-in text editor for immediate changes.
